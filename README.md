## 🚀 Featured Projects

### 💳 Payment Processing & Reconciliation System

A backend system designed to process payments and reconcile internal payment records with simulated provider reports.

**Tech Stack:** Go, Gin, GORM, PostgreSQL, JWT, Docker

- Payment lifecycle management
- JWT-based authentication
- Idempotency handling
- Database transactions and concurrency safety
- Provider transaction reconciliation
- Background reconciliation workers
- REST APIs with Swagger documentation

### 🛒 Full Stack Shopping Application

A full-stack e-commerce application with separate user and admin functionality.

**Tech Stack:** React, TypeScript, Node.js, Express, PostgreSQL, Supabase, Firebase

- Google Authentication
- Product and category management
- Shopping cart functionality
- Order management
- Admin dashboard
- REST API integration

### 🧠 SoloLearn Intelligent Proctoring System

An online examination monitoring system developed during my MERN Stack internship.

**Tech Stack:** React, Node.js, Express, MongoDB, WebRTC, Gemini API

- Webcam-based monitoring
- 360° proctoring functionality
- Canvas-based snapshots
- AI-assisted examination monitoring
- Secure backend APIs
